### 📦 Installation:
1. Download complete package
2. Upload theme to `/wp-content/themes/gst-invoice-pro/`
3. Upload plugin to `/wp-content/plugins/gst-invoice-pro/`
4. Activate both from WordPress admin
5. Go to GST Invoice menu and start using!
